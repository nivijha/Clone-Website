# **Sidcup Family Golf Clone**
This is a web development project aimed at replicating the design and functionality of Sidcup Family Golf. The goal is to enhance web development skills by recreating a professional, responsive, and interactive website.

## Features
 Responsive Design: Ensuring a seamless experience across all devices.
 Modern UI/UX: Implementing a visually appealing layout.
 Interactive Elements: Navigation menus, booking forms, animations, etc.
 Optimized Performance: Fast loading times and smooth user experience.

## Technologies Used
HTML, CSS, JavaScript

## Installation & Setup
### Clone the repository:
`git clone https://github.com/nivijha/Clone-Website-clone.git`	

Navigate to the project directory:
`cd sidcupfamilygolf-clone`

Open index.html in a browser.
